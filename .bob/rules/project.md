# Intro Bob Workshop - Project Rules

## Project Context
This is the IBM Bob intro workshop repository. It contains lab documentation (Markdown),
workshop exercises, and supporting materials. There is no application source code.

## Conventions
- All content lives under `docs/lab-*/README.md`
- Bob documentation references should be verified against IBM docs before being written
- Code examples in the docs should be minimal, correct, and runnable

## Do Not Change
- Do not modify the overall lab structure or numbering without explicit instruction
- Do not add external dependencies or package files
