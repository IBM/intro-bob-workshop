# Lab 6 Agent Redesign Plan

## Top-Level Overview

**Goal:** Redesign `docs/lab-6/README.md` so that the three role-based tracks each center on
participants *building an agent* — a system with a plan → act → evaluate → output loop —
rather than using Bob to generate one-off artifacts.

**Scope:** `docs/lab-6/README.md` only. `docs/lab-6b/README.md` and all other labs are
out of scope. No new files are committed to the repo; all code is generated by Bob
during the workshop session (consistent with existing workshop conventions).

**Approach:**
- Keep the warm-up (Part 1) and the overall 60-minute structure unchanged.
- Redesign Part 2 (the three tracks) so each track is framed as "build an agent for
  your role."
- Update Part 3 (participant-driven activity) to explicitly ask participants to design
  their own agent rather than a generic artifact.
- Add a short "Anatomy of an Agent" explainer before Part 2 so all audiences share a
  common vocabulary before branching into tracks.
- Update framing language, key takeaways, and facilitator guide to reflect the new focus.

**Execution constraint:** Developer track (Track A) produces fully runnable Python code.
PM/Exec track (Track B) and Educator track (Track C) use Bob-driven execution — Bob
builds and runs the agent inside VS Code; participants direct via prompts and review
output. No terminal or install required for Tracks B and C.

**Non-goals:**
- Do not change lab structure, timing, or audience targeting.
- Do not add new files or sample data to the repo.
- Do not change Lab 6B.
